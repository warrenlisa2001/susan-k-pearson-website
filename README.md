## Development

### Local Setup
```bash
# Build the project
npm run build

# Start development server with PM2
pm2 start ecosystem.config.cjs

# Test the service
npm test

# Check logs
pm2 logs elemental-healing --nostream
```

### Deployment to Cloudflare Pages
```bash
# Build the project
npm run build

# Deploy to Cloudflare Pages
npm run deploy:prod
```
